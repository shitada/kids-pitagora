# ⚙️ ころころピタゴラこうじょう — Kids Pitagora Factory

5〜10歳向けの3D物理パズル。パーツをおいて、ボールをゴールまで はこぼう！

🎮 プレイはこちら → https://shitada.github.io/kids-pitagora/

iPad Safari での横向きプレイに最適化されています。

---

## ゲーム概要

- ⚙️ **おく → ▶ためす → なおす** の くりかえしで ゴールを めざす物理パズル
- 🎯 ボールは じぶんで うごかせない。**そうちを つくって** はこぶのが しごと
- 🧩 いた・ジャンプだい・せんぷうき・ベルトコンベア・ドミノ・パイプ・ふりこハンマー の7パーツ
- 🏁 ぜん15ステージ。すすむほど つかえるパーツが ふえる
- ⭐ ステージごとに ★3つ（クリア / パーツすくなく / ★コインぜんぶ）
- 🛠️ **じゆうこうさく** モードで すきなように そうちを つくれる（3スロットに ほぞんできる）
- 📖 **はつめいずかん** でパーツのしくみを まなべる（ほんものの物理エンジンで うごく）
- 🎆 ぜんステージクリアで はなび演出！

## あそびかた

1. がめん下の トレイから パーツを **ドラッグ&ドロップ** して おく
2. おいた パーツを タップすると **回転ハンドル** が出る（PC はホイールでも回せる）
3. いらない パーツは **ゴミばこ** へドラッグして けす
4. **▶ スタート** で ボールが おちて 物理シミュレーションが はしる
5. うまくいかなければ **⏹ リセット** して なおす

## パーツと まなべること

| パーツ | 挙動 | まなべること | 解放 |
| --- | --- | --- | --- |
| 🪵 いた | 角度を回せる固定の坂 | さかと じゅうりょく | St1 |
| 🦘 ジャンプだい | 法線方向へ「ぼいん」と はねかえす | はねかえる ちから | St4 |
| 🌬️ せんぷうき | 向き付きの風力を範囲に加える（距離で減衰） | よこむきの ちから | St7 |
| ⏩ ベルトコンベア | 接触中のボールへ横方向の速度を与える | まさつと はこぶ ちから | St10 |
| 🀄 ドミノ | 倒れて隣に連鎖し、ボールを押す | れんさと ちからの つたわりかた | St10 |
| 🌀 パイプ | 曲がり管。入るとレールに沿って導かれる | みちの コントロール | St13 |
| 🔨 ふりこハンマー | 周期的に振れてボールを打ち出す | ふりこと タイミング | St13 |

## 物理エンジンについて

このゲームの心臓部は `src/game/physics/` の **2.5D 固定平面ソルバー** です。

- 見た目は奥行きのある 3D ジオラマですが、**シミュレーションは z を固定した XY 平面のみ**
- **固定タイムステップ 1/120 秒**。描画フレームレートから完全に独立した決定論的シミュレーション
- 衝突判定は「円（ボール）vs OBB / Capsule / Circle」だけ。汎用の凸包判定は不要
- 物理コードは **Three.js に依存しない**（純粋な数値計算モジュール）
- 物理パラメータは `src/game/config/physics.ts` に集約

決定論であることを活かして、**全15ステージが想定解で★3を取れることを Vitest が自動検証**しています
（`tests/unit/stages-solvable.test.ts`）。これがこのプロジェクト最大の品質保証です。

## ディレクトリ構成

```
src/
├── main.ts                  # App（唯一の rAF ループ）とシーン遷移
├── types/                   # 共有型
├── game/
│   ├── config/              # physics / parts / stages / palette（数値とデータの集約）
│   ├── physics/             # Three.js 非依存の決定論ソルバー
│   ├── parts/               # Placement → ワールド実体、配置バリデーション
│   ├── render/              # Three.js の描画のみ
│   ├── input/               # Pointer Events の処理のみ
│   ├── audio/               # Web Audio API のみ
│   ├── scenes/              # 画面遷移とゲーム進行
│   └── storage/             # localStorage
└── ui/                      # DOM の UI 部品
tests/unit/                  # Vitest（156 テスト）
```

## 開発

```bash
npm install
npm run dev     # ローカル開発サーバー
npm test        # Vitest（15ステージの★3検証を含む）
npm run build   # tsc + vite build
npm run preview # 本番プレビュー
```

**ステージ定義や物理パラメータを変更したら、必ず `npm test` を通してください。**

Copilot 向けの実務ルールは `.github/copilot-instructions.md` と `.github/skills/` に整理しています。

## 安全・権利について

- 暴力・流血表現ゼロ。課金・広告・外部リンク・オンライン通信・チャットなし
- 個人情報を収集しません。セーブは localStorage のみで、外部に送信しません
- 色覚に配慮したパレットを使い、色だけに頼らず絵文字・形・文字でも情報を伝えます
- 実在するテレビ番組・キャラクター・ロゴ・音源を一切使用していません。
  「ピタゴラ」は装置ジャンルを表す一般的な日本語表現として用いており、
  ビジュアル・音楽・キャラクターはすべてオリジナルです
